Normal Mapping

Lighting bumps and dents that aren’t in the geometry: normal maps, tangent space and the TBN matrix.

THE IDEAWhat is normal mapping?

Lighting depends on the surface normal. A normal map gives every pixel its own normal, so flat triangles light up as if they had bumps.

The geometry doesn’t change. The demo on the right is two triangles.

move the mouse over the picture to move the light
Also called Dot3 bump mapping. It is a cheap way to add detail to a low-poly model.

NORMAL MAPAn image full of directions

stones · normal map

Each texel stores a direction instead of a color: R → x, G → y, B → z.

hover the normal map

The arrow is the normal seen from above. x points right, y points down the image (the same way +V goes), z points out of the surface.

A flat surface’s normal is (0, 0, 1). Encoded, that is (0.5, 0.5, 1.0), a light blue. That is why normal maps look mostly blue.

NORMALSVertex normals vs. map normals

light angle

A flat triangle has one normal, so its lighting is flat. The map gives every pixel a normal tilted like the real bumpy surface (dashed).

MATERIALAlbedo + normal map

click a map to switch it on or off

The albedo is the base color of the surface. The normal map holds the normal vectors that lighting uses.

“N as color” shows the final normals as RGB. That view is a good way to debug.

WHERE THEY COME FROMBaking detail into a map

From a high-poly model: artists sculpt millions of triangles (ZBrush, Blender), then bake the detail into a normal map for a low-poly model with the same UVs.

From a height map: a grayscale bump image becomes normals by measuring its slope in x and y. Many tools (Substance, GIMP, Photoshop) can do this.

TANGENT SPACEMap normals are relative

In a normal map, +z means “straight out of this surface”, not “toward world +Z”. The same map has to work on every face of the model.

drag to rotate the model

TANGENT SPACETangent, bitangent, normal

Every vertex gets its own small set of axes, lined up with the texture:

  • Tangent points along +U (red in the texture)
  • Bitangent points along +V (green in the texture)
  • Normal points out of the surface

The mesh file gives you N and T. B can be computed: B = cross(N, T).

texture: red = U, green = V

MATHAn orthonormal matrix rotates

rotating about z · view tilted so z shows

Orthonormal: the three rows are unit length (length 1) and perpendicular to each other. Each row is one of the object’s local axes.

This is how we move a vector into a different space. v is written in local coordinates; multiplying by the matrix of that space’s axes gives the same vector in world coordinates. The TBN matrix does exactly this for map normals.

TBN MATRIXThree axes in one 3×3 matrix

TBN =
T.xT.yT.z B.xB.yB.z N.xN.yN.z
  • Built from three orthonormal vectors, so it is a pure rotation.
  • Takes a normal from tangent space (the map) to world space.
  • Its inverse is its transpose, which is cheap.
mul(n, TBN) = n.x·T + n.y·B + n.z·N
